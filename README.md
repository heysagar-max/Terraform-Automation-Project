# Terraform Automation Project

## Project Overview
This project demonstrates AWS infrastructure provisioning using Terraform automation.

## AWS Services Used
- EC2
- VPC
- S3

## Technologies Used
- Terraform
- AWS Cloud

## Project Structure

EC2/
Contains Terraform configuration files for EC2 instance provisioning.

VPC/
Contains Terraform configuration files for VPC and networking setup.

S3/
Contains Terraform configuration files for S3 bucket creation.

variable/
Contains Terraform variable definitions.

output/
Contains Terraform output configuration files.

## Terraform Commands

Initialize Terraform:

terraform init

Preview Infrastructure Changes:

terraform plan

Apply Infrastructure:

terraform apply

Destroy Infrastructure:

terraform destroy

## Features
- Infrastructure as Code (IaC)
- Automated AWS Resource Provisioning
- Modular Terraform Configuration
- Reusable Infrastructure Setup
